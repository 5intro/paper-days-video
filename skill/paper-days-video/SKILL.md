# 纸间日常 · Paper Days

接收一个选题，负责从研究到完整视频。先判断是科普/心理/哲学，还是 vibecoding 产品；不要求用户预写 `episode.json`、时间轴或素材清单。已有确认稿时保留原意和范围。缺少会实质改变作品的信息才问；用户要求先审稿时，先交稿等待，不从沉默推定同意。

## 制作顺序

1. 阅读 [风格](references/style.md)；按模式读 [科普叙事](references/research-story.md) 或 [产品叙事](references/product-story.md)。检索一手研究或实际产品事实，做来源与论断对应表。
2. 把面向观众的问句、具体生活困扰、解释/操作和结果组织成连贯叙事；产生锁定中文稿、自然英文字幕、分镜与简介。痛点必须说清，避免两句话就跳到方案。合理轻幽默，不强行口号。
3. 按 [流水线](references/pipeline.md) 建独立项目。自动检查依赖、下载固定公开字体和模型，遵循当前执行权限。读取 [声音运行](references/voice-runtime.md) 生成逐段配音并保留断点；不默默降级声线。
4. 保存 ASR 原始观测，结合真实活动边界和词时码制作对齐文件。发音 alias 只改 TTS 副本，字幕仍用锁稿。ASR 不等于主观听审，不用预计字数时长充当最终时间轴。
5. 为本选题编写原创 `scenes.py`，复用生活物件画法但不复制旧选题内容。产品模式按用户范围选择真实应用、可交互原型或原创 UI 动画；保持独立精致 UI 与可信操作逻辑，准确区分演示形态。让动作落在口播对应词处。
6. 生成抽帧与双封面、检查字幕和构图，再渲染 1080×1920 / 24 fps。按 [混音](references/audio-mix.md) 使用默认授权音乐或用户自己的合法音乐，保留明显可听的底色和清楚人声。
7. 按 [交付检查](references/quality.md) 查看画面、对齐与音频证据，修复可恢复问题，输出 MP4、双封面、SRT、简介、来源说明和可编辑项目；复用随包 CC BY 素材时按 [素材许可](LICENSE-ASSETS.md) 保留署名、许可链接与改动说明。只有真实完成的检查才能标记通过。

## 风格底线

暖纸色、柔灰绿、克制轮廓、具体生活物件贯穿始终；中文字幕主、英文小、无框、下约四分之一位置且避平台遮挡。不要用满屏卡片和长解释文字代替动画。柔和、目的明确的音效，避开刺耳提示音。

研究模式区分证据、解释与隐喻，不虚构数字或治愈承诺。产品模式不把视频纸纹复制进产品 UI，不反复口播“只是原型”；在简介一次准确披露真实实现程度。尊重当前权限；本 skill 不授予发布、付款、外部访问或真人音色克隆的权限。
