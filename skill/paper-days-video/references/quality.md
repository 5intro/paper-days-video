# 交付检查

## 视觉与同步

- 看每个镜头开、中、尾与转场；确认道具连续、无闪烁、无异常裁切。
- 检查中文字幕与锁稿逐字一致，英文不增加事实；没有字幕框、画面文字竞争或平台区遮挡。
- 核对关键动作相对真实词时码的位置，而非只看整段长度。
- 产品模式核对演示动作与其形态一致：真实应用/原型动作要对应实际状态，原创 UI 动画要有可信状态逻辑且准确披露，不能把动画说成已经上线的功能。双封面逐张检查比例、标题与安全区。

## 音频

- 保存 TTS 原件和单次 1.1 倍速结果；混音不再次变速，不把音乐长度硬拉伸。
- 逐段看 ASR 原始观测与锁稿差异；同音词可能是字形问题，必要时做一次有针对性的交叉识别或听审。不能仅因 ASR 字形不同认定配音错字。
- 用语音活跃窗口评价清晰度，尤其较轻句、音乐高能量处和结束尾音。音乐明显可听但不盖人声，避让平滑，无逐字抽吸。
- 目标响度约 -16 LUFS，真峰值预留 AAC 余量约 ≤ -1.8 dBTP；这不是主观听感的替代品。
- `audit_media.py` 的测量、ASR 和画面检查分开记录。主观听审仅在确实可听并完成时填写；不能把模型识别通过写成“听感验收通过”。

## 文件

输出 `delivery/main.mp4`、`cover-3x4.png`、`cover-4x3.png`、`subtitles.srt`、`description.txt`、`sources.md` 与编辑项目。MP4 H.264 / yuv420p + AAC / 48 kHz，尺寸 1080×1920，24 fps；视音频长度匹配，没有截尾。

最终 `delivery/manifest.json` 记录各文件 SHA-256、时长、规格、声音/音乐来源、实际完成的检查及发现。文案里的 AI 或演示说明与实际制作相符。提交交付物即结束制作范围；上传社交平台需另行明确请求。

## 素材署名

复用本包音乐、参考声线或原创视觉设计时，在简介、片尾或随作品提供的素材说明中保留 `5intro / Paper Days`、项目链接、CC BY 4.0 链接，并注明实际修改。可复制项目 README 的署名行。仅使用代码或独立新创作时，不强制把所有新作品套用同一素材许可；第三方素材按各自许可处理。
